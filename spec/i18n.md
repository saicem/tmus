# 国际化

## 多语言

- 前端多语言配置在 `src/lib/i18n.ts`，组件通过 `useI18n()` hook 读取当前语言的文案
- 后端多语言配置在 `src-tauri/src/state/i18n.rs`（托盘菜单等）

## 语言判定

- 设置中可选择 `zh` / `en` / `system`
- 选择 `system` 时，优先使用 `navigator.language`（WebView 的系统显示语言），回退到 Tauri OS 插件 `locale()`
- 解析出的系统语言缓存在全局 store（`systemLang`），从 `zh`/`en` 切回 `system` 时恢复显示
